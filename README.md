# Yilda Form — Releases

Este repositorio es el canal de actualizaciones del plugin de WordPress **Yilda Form** (complemento de Yilda Draw, de Yilda Studio).

**Acá no vive el código fuente del plugin.** Cada versión se publica como una [Release](https://github.com/YildaStudio/yilda-form-releases/releases) de GitHub, con el .zip del plugin ya armado adjunto. WordPress lo lee automáticamente a través de [Plugin Update Checker](https://github.com/YahnisElsts/plugin-update-checker) para mostrar avisos de actualización en el panel de administración, igual que con cualquier plugin del repositorio oficial de WordPress.org.

Yilda Form no está publicado en WordPress.org — se distribuye directamente a los clientes de Yilda Studio.

Más información: https://yildastudio.com/yilda-form-help/
